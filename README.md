# thomasfleron — Professional Mobile Technology Website V1

Static multi-page smartphone and mobile technology website prepared for GitHub Pages.

## Pages
- Home
- Shop
- Smartphones
- Accessories
- Audio
- Smart Devices
- About
- FAQ
- Contact
- 404

## Important
All product names, prices, specifications, availability, warranty claims and forms are demo content until officially verified.
The shopping cart is a visual demo and does not process payments.
Forms are static and need a backend or email integration.

## GitHub Pages
Upload the unpacked files to the root of `thomasfleron.github.io`.
Then go to Settings → Pages → Deploy from branch → `main` → `/(root)` → Save.
